# Fern, Beyond the Screen

A personal, independent dating-introduction website for Fern. Not a dating service or a companion to the professional résumé site.

Visual direction: oxblood, burgundy, cream, antique gold, and an Amanita muscaria woodland motif.

The site is a static website: `index.html` and `assets/*`. It uses no database, user accounts, tracking, or submission forms. Connection is through the dating platform where the visitor discovered Fern's profile.
